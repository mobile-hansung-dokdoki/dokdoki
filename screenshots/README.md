# MP2 화면 증빙

개발자가 촬영한 실제 휴대폰 캡처를 이 폴더에 넣습니다. 캡처를 새로 만들 필요는 없으며 이미 찍어 둔 파일을 사용합니다. 아래 이름은 권장 이름이므로 기존 파일명으로 보관한다면 어떤 화면인지 알아볼 수 있게 구분합니다.

| 증빙 | 권장 파일명 | 확인할 내용 |
|---|---|---|
| 수정 | `mp2_edit.png` | 수정 화면 또는 수정된 항목의 내용 |
| 삭제 | `mp2_delete.png` 또는 삭제 전후 두 장 | 삭제 결과가 드러나는 목록 |
| 전체 필터 | `mp2_filter_all.png` | 완료·미완료 항목이 함께 표시 |
| 완료 필터 | `mp2_filter_done.png` | 완료한 항목만 표시 |
| 미완료 필터 | `mp2_filter_active.png` | 진행중 탭에서 미완료 항목만 표시 |
| 재시작 전 | `mp2_restart_before.png` | 종료 전 항목과 완료 상태 |
| 재시작 후 | `mp2_restart_after.png` | 같은 항목·완료 상태가 복원된 화면 |
| 카테고리 | `mp2_category_list.png` | 다른 카테고리의 이름과 색상 |
| 카테고리 수정 | `mp2_category_edit.png` | 카테고리를 선택·변경하는 화면 |
| 검색 | `mp2_search.png` | 검색어와 검색 결과 |
| 완료율 | `mp2_progress.png` | 전체·완료 개수, 퍼센트, 진행 막대 |

한 장에 여러 기능이 명확히 보이면 같은 화면을 중복 촬영할 필요는 없습니다. 교수님 기본 제출 요구는 수정·삭제·필터 화면과 재시작 전후 비교입니다. 카테고리·검색·완료율은 팀 명세서의 추가 기능 증빙입니다.

**현재 이 안내 파일 자체는 캡처가 아닙니다. 휴대폰의 실제 이미지 파일을 옮긴 후 제출해야 합니다.** 개인정보가 들어 있지 않은 테스트 항목으로 촬영한 파일을 사용합니다.
