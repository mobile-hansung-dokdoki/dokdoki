# MP2 실제 기기 캡처

AI로 생성하거나 화면 내용을 합성하지 않았다.

| 파일 | 검증 내용 |

| [05_filter_pending.jpg](05_filter_pending.jpg) | 미완료 항목 2개만 표시 |

06은 홈, 07은 검색 화면이다. 두 화면에 동일한 남은 항목과 완료 상태가 나타난다.
종료 과정 자체는 사진에 나타나지 않으며 사용자가 완전 종료 후 재실행했다고 확인했다.
상단 ‘비 동기화’는 서버 동기화 상태로, 하단 로컬 저장 완료와 별개이다.
